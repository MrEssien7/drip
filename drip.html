Drip.

A small companion for Claude Code on Windows. It hangs from the top edge of your screen, shows what your session is doing, and asks you before Claude runs anything that needs permission. This is a prototype: every event below is simulated.

      What does parseHourly return?
      
              
      An array of HourlyPoint objects, one per hour, each with a temperature in °C and a rain chance from 0 to 1.
      
            
      
            
      
              
              
            
      
          
      
        
      
      
      

      
      
        
      forecast.tsweather-cli
      
        
      export function parseHourly(raw: ApiHour[]) {
  return raw.map(h => ({
    time: new Date(h.ts * 1000),
    tempC: round1(h.temp),
    rain: h.pop,
  }));
}

      What each hook does
      
    
      
      
      
        
      Hook eventDrip
      
        
          
      SessionStartWakes up and shows the compact pill with the project name.
      
          
      UserPromptSubmit
      PreToolUse      		Turns blue and busy. Adds the step to the activity list.
      
          
      PostToolUse
      PostToolUseFailure      		Marks the step done (green) or failed (red).
      
          
      PermissionRequestOpens, turns amber, bounces. Holds the hook open up to 115 s for Deny, Allow or Always allow. No answer prints nothing, so Claude Code asks in the terminal.
      
          
      StopShows the summary in green, folds to the pill after 10 s, hides after 15 s more.
      
          
      StopFailureOpens in red with the error.
      
          
      SessionEndHides back into the top edge.
      
              
      
      
    
      
    
      Porting to Tauri: everything above runs through one function, applyHook(payload), in this page's script. In the real app, a small relay exe receives the hook's stdin, sends it over a named pipe to the Rust side, which forwards it to the front end with emit("hook", payload). The front end calls the same applyHook.
